# Page Design Guidelines

- One primary action per page.
- Prefer tables/forms over decorative cards for operational screens.
- Respect existing MUI patterns in the codebase.
- Landing/marketing pages follow brand-first hero rules; app shells stay utilitarian.
- See [01-design-system.md](./01-design-system.md) and [03-layout-guidelines.md](./03-layout-guidelines.md).
