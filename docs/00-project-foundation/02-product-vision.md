# Product Vision

Transform Hotel/Business Billing into **Prabha Billing SaaS**: professional multi-business billing and management for Indian SMBs, sold by Prabha Technology Pvt. Ltd.

## Outcomes

| Outcome | Description |
|---------|-------------|
| One platform | Shared engines + 14 industry packs |
| Configurable commerce | Master-managed plans, trial, features |
| Safe tenancy | Strict isolation; never trust client `tenant_id` |
| Extensible | New business type via config + module pack |

## Non-goals

Medical/pharmacy modules · Rewriting working Master/auth/billing from scratch · Unapproved production schema drops
